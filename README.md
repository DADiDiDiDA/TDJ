# 天地劫：幽城再临 · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。
> 有需要直接 copy 改造即可，不用问我，也无需另行告知。
> 模拟器仅在 Mumu 模拟器上测试过；若运行在 PC 端，则仅在官方服（官服）测试过。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **进入游戏**：自动登录游戏（启动游戏最好在设置里执行，这个不能开启游戏）
- **领取邮件**：自动领取邮件。
- **赠送友情点**：自动向好友赠送友情点（只有同服好友）
- **山河志派遣**：自动进行山河志派遣。
- **刷灵脉光渊**：刷一次灵脉光渊并领取旧世奖励。
- **刷蚀之隙**：刷一次第一章简单难度的蚀之隙，以完成日常任务。
- **刷体力**：消耗体力进行扫荡。
- **天地阁加速**：自动执行天地阁加速。
- **幻境挑战**：自动进行一次幻境挑战。
- **每日免费召唤**：进行每日免费召唤一次。
- **通关文牒奖励**：自动领取通关文牒的奖励。
- **周常处理**：自动处理旧世周常、三途川扫荡及周常奖励领取。
- **领取历练奖励**：自动领取历练任务的每日奖励。

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 使用**官方 PC 端**运行（模拟器未经测试）
- 分辨率建议 **1920 × 1080**
